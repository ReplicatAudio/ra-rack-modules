# ra-zeno — Slowdown / Halftime Effect

Records a signal into a buffer and plays it back slowed down by 1×–16×, with optional zero-crossing smoothing on reset.

## Controls
- **Slow**: playback speed reduction (1×–16×).
- **Snap**: snaps the slowdown factor to half-steps.
- **Reset**: restarts playback from the read head (with crossfade).

## Inputs
- **Signal**: audio to record and slow down.
- **Slow CV**: modulates the slowdown factor.
- **Reset**: trigger to reset playback.

## Outputs
- **Signal**: slowed playback output.
