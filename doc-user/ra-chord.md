# ra-chord — CV Transposer

Transposes a single pitch CV to four outputs, each with its own semitone offset.

## Controls
- **Ch 1–4 Offset**: per-output transpose in semitones (−16 to +16, snaps to integer).

## Inputs
- **Input**: pitch CV to transpose.

## Outputs
- **Output 1–4**: input plus the corresponding offset (1 V / 12 semitones).
