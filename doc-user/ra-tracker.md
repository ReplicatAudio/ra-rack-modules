# ra-tracker — Tracker Sequencer

Four-channel step sequencer with a tracker-style screen interface.

## Controls
- **Channel 1–4**: value knob for the selected step of each channel (0–10 V).
- **Write / Clear**: edit actions for the current step.
- **Step up / Step down**: move the edit cursor.
- **Seq next / Seq prev**: move between sequences.

## Inputs
- **Step up / Step down / Seq next / Seq prev / Write / Clear**: trigger inputs for the corresponding actions.

## Outputs
- **CV 1–4**: per-channel step value outputs.
