# ra-m2 — Stereo Master Processor

Stereo master output processor with gain, limiting, soft clipping, stereo-to-mono mix, and mute.

## Controls
- **Master gain**: output level (0–200%).
- **Stereo→mono**: blends both channels toward a mono sum.
- **Limiter (-6dB)**: hard-clips output to ±5 V.
- **Soft clip**: applies soft saturation.
- **Mute**: toggle button (also Space key); LED pulses while muted.

## Inputs
- **Left / Right**: stereo input.

## Outputs
- **Left / Right**: processed stereo output.
