# ra-macrow — Macro CV Source

A single macro knob that drives four outputs, each with its own attenuverter and offset.

## Controls
- **Macro**: master knob (range set by the Range switch).
- **Range**: ±5 V or 0–10 V.
- **Atten 1–4**: per-output attenuverter (bipolar scale).
- **Offset 1–4**: per-output voltage offset.

## Inputs
- **Macro CV**: external CV overrides the macro knob.

## Outputs
- **Output 1–4**: `macro × attenuverter + offset` per output.
