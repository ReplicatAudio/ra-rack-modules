# ra-quant — Pitch Quantizer

Eight-channel pitch quantizer that snaps 1 V/oct CV to the nearest semitone of a selectable scale.

## Controls
- **Pre-offset**: semitone offset applied before quantizing (−12 to +12 st).
- **Quantize offset**: when on, the offset itself is quantized.

## Inputs
- **Offset CV**: CV that modulates the pre-offset.
- **Pitch 1–8**: pitch CV inputs.

## Outputs
- **Pitch 1–8**: quantized pitch outputs.
