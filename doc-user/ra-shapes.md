# ra-shapes — VCO

VCO producing five simultaneous waveforms.

## Controls
- **Frequency**: coarse pitch control.
- **Slow mode**: divides the frequency by 8.
- **FM 1 / FM 2 attenuation**: amount of FM applied per FM input.
- **Phase**: phase offset (0–100%).

## Inputs
- **1V/Oct**: exponential pitch CV.
- **FM 1 / FM 2**: frequency modulation inputs.
- **Phase CV**: modulates the phase offset.

## Outputs
- **Sine / Triangle / Saw up / Saw down / Square**: the five waveforms, ±5 V.
