# ra-vnote — Vertical Note

A tiny 3 hp text box for writing quick labels and notes directly on the rack, working like VCV's built-in Note module but in a narrow vertical format.

## Usage
- The text area has padding all around it. **Click** it to start typing — the text is rendered vertically, bottom-to-top, centered in the module: a single large column when the note is short, with the view scrolling to follow the caret as it grows.
- The note is saved with the patch and restored when you reopen it.
- It has no inputs, outputs, or knobs — it's purely a label for the patch.

## Hints
- Click once to focus and edit; click anywhere else to finish.
- "ReplicatAudio" is shown as a placeholder while the field is empty.
- Long notes wrap into additional columns at the same large size; the view scrolls to follow the caret.
