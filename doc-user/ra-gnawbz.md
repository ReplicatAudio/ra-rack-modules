# ra-gnawbz — 3-Channel CV Source

Three independent manually-set control voltage outputs.

## Controls
- **Knob 1–3**: output level (0–100%).
- **Range 1–3**: output range, ±5 V or 0–10 V.
- **Scale 1–3**: scales the knob into the output range.

## Outputs
- **Output 1–3**: the corresponding CV output.
